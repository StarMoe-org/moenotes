# Moenotes — 星轨上的音符

设计核心：每一条资料是一枚音符，浏览是在星轨中寻找、连接这些音符。签名是人的痕迹，轨道是资料的秩序，天狼星是当前位置。

## 四条规则

1. **方向**：沿签名的右上走势建立约 12° 的斜线。分隔、轨迹、装饰均从这条方向派生，不随机旋转正文与图片。
2. **轮廓**：主视觉使用对角切口；可交互面板使用对角直角与圆弧的组合，像轨道截面。留足内容与焦点环空间，不裁切表单。
3. **重音**：雾蓝是结构色，冰蓝是光。选中导航和弹窗标题采用半透明的蓝色重音：浅色模式使用深蓝文字，深色模式使用冰蓝文字，让重音融入玻璃底板。四芒星表示当前位置，不到处重复充当贴花。
4. **材质**：玻璃用于层级与透景，密集数据保留清晰底色。正文保持水平；插图保留原色。微动效朝轨道方向移动，尊重减少动态与减少透明度设置。

## 标识

公共 BrandLogo 组件统一引用签名 SVG；深浅模式切换不同色版。标题栏、侧栏、页脚、首页、设计系统使用同一笔画，不额外叠字。签名字标用于品牌，不替代小尺寸功能图标。

## 验收

隐藏星星图案后，仍应能从对角轮廓、雾蓝重音、斜向轨迹认出 Moenotes。不能只靠蓝紫渐变判断主题。所有核心语言保持同等可用，手机端不牺牲点击面积。
