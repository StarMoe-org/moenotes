# Moenotes Rounded Font Notice

This notice applies only to the font files distributed under `public/fonts/`.

## Font name

The web font used by this project is called **Moenotes Rounded**.

The Simplified Chinese locale-specific subset is named **Moenotes Rounded SC** in font metadata so that `zh-CN` pages can prefer the Simplified Chinese subset.

## Source font

Moenotes Rounded is a modified version of **Nowar Rounded**:

- Source repository: <https://github.com/nowar-fonts/Nowar-Rounded>
- Original license: **SIL Open Font License 1.1**
- Original reserved font names include: `Nowar`, `有爱`, `有愛`

The full OFL text and original copyright notice are kept in:

- [`OFL-Nowar-Rounded.txt`](./OFL-Nowar-Rounded.txt)

## Modifications

The original Nowar Rounded font was modified for this project. The modifications include:

1. Renaming the derivative font family to **Moenotes Rounded** / **Moenotes Rounded SC**.
2. Converting the selected font data to **WOFF2** for browser embedding.
3. Subsetting the glyph coverage to make the font suitable for web embedding.
4. Removing large unused character coverage such as Korean Hangul, CJK Extension A, rare ideographs, and unused glyphs.
5. Creating a Simplified Chinese subset for `zh-CN` pages and a common CJK subset for Japanese/common fallback usage.

These modifications are intended to reduce download size and make the font practical for embedded web environments.

## Distributed font files

The current derived font files are:

- `MoenotesRounded-400.woff2`
- `MoenotesRounded-700.woff2`
- `MoenotesRoundedSC-400.woff2`
- `MoenotesRoundedSC-700.woff2`

# Moenotes Rounded 字体声明

本声明仅适用于 `public/fonts/` 目录下发布的字体文件。

## 字体名称

本项目使用的网页字体名称为 **Moenotes Rounded**。

其中，简体中文页面使用的专用子集在字体元数据中命名为 **Moenotes Rounded SC**，用于让 `zh-CN` 页面优先使用简体中文子集。

## 源字体

Moenotes Rounded 是基于 **Nowar Rounded** 制作的修改版字体：

- 源仓库：<https://github.com/nowar-fonts/Nowar-Rounded>
- 原始许可证：**SIL Open Font License 1.1**
- 原始保留字体名称包括：`Nowar`、`有爱`、`有愛`

完整 OFL 文本与原始版权声明保留在：

- [`OFL-Nowar-Rounded.txt`](./OFL-Nowar-Rounded.txt)

## 修改内容

我们对原始 Nowar Rounded 字体进行了适配修改，包括：

1. 将修改版字体族重命名为 **Moenotes Rounded** / **Moenotes Rounded SC**。
2. 将选定字体数据转换为适合浏览器嵌入的 **WOFF2** 格式。
3. 对字形覆盖范围进行子集化，减少网页嵌入所需体积。
4. 移除韩文、CJK Extension A、生僻字以及未使用字形等大型未用字符覆盖。
5. 为 `zh-CN` 页面制作简体中文专用子集，并保留一组用于日文/通用 fallback 的 CJK 子集。

这些修改的目的，是让字体更适合网页嵌入环境并减少下载体积。
